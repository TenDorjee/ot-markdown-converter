# Installing or Using any Third party Software or Application on an Advanced Authentication Appliance Server

## Summary

Installing or using any Third party Software or Application on an Advanced Authentication Appliance Server

## Environment

Advanced Authentication\
AA 6.x (AAF server) based on SLES 12 or SLES 15 Appliance

## Situation

Is installing other software on an Advanced Authentication appliance server supported?

Customers have inquired about the supportability of installing third-party software on the SLES server hosting the Advanced Authentication (AA) Appliance. In certain scenarios, administrators may need to install approved third-party applications, such as administrative utilities, backup solutions, monitoring tools, or antivirus software, to support operational requirements while ensuring that AA functionality, stability, and update processes remain unaffected.

## Resolution

While it is possible to install other software on the AA server, Installation and usage of any other General-Purpose Software or Licensed Applications is Not permitted by the End User License Agreement (EULA) and doing so violates the EULA, and is therefore not officially supported.

OpenText has licensed SLES Appliance for the sole purpose of running the AA Product; not for other software applications or tools that user prefers to install.

Refer to Additional License Authorizations (ALA) document on Identity and Access Management Products for more details.\

### Important Considerations Prior to Installing Permitted Third-Party Applications That Comply with the SLES Appliance License Agreement (ALA) above

- Compatibility between third-party applications and their associated dependencies is not officially tested or validated as part of Advanced Authentication (AA) product upgrades, patching activities, or Online Updates (port 9443) delivered through the dedicated AAUTH Appliance Update channels.
- It is recommended to maintain an inventory of all third-party applications, related dependency packages, and their respective versions that have been manually installed on the AAF Appliance. Maintaining such records can help identify, track, and mitigate potential issues during future AA upgrades or underlying SLES version upgrades that may be caused by these third-party components.
- Before performing any AA upgrade, migration, or system update, ensure that a current AAF Appliance snapshot and/or backup is available. This provides a recovery option in the event of issues arising from installed third-party applications or their dependencies.
- Third-party tools, add-on packages, and their dependencies installed on the AAF Appliance may not be preserved following an upgrade or migration to a newer AA and corresponding SLES version. Administrators may be required to reinstall compatible versions from supported software sources after the upgrade is completed.
- OpenText Technical Support does not provide installation, maintenance, troubleshooting, or update services for such third-party applications installed on the AAF Appliance. Management of such software remains the sole responsibility of the AA Administrator.
- AA Online Updates do not deliver security fixes, patches, or maintenance updates for third-party applications or their related dependencies that have been installed from external repositories or non-AA update channel.
